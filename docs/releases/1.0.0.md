# AgentShield 1.0.0 Release Notes — General Availability (GA)

Release date: 2026-08-14

## Scope

AgentShield 1.0.0 marks the official **General Availability (GA)** release of AgentShield, featuring the new Interprocedural Call-Graph Taint Engine for deep cross-function and cross-method security analysis, along with fully stabilized public APIs and multi-framework runtime guarantees.

## Notable changes

- **Interprocedural Call-Graph Taint Engine (`src/analysis/interprocedural.rs`)**:
  - Automatically constructs interprocedural call graphs across Python and TypeScript modules.
  - Propagates taint across call boundaries when tool handlers pass untrusted inputs through utility helpers, wrapper functions, and class methods before reaching execution sinks.
  - Generates multi-hop `TaintPath` chains (`source` $\to$ `through: [helper1, helper2]` $\to$ `sink`) with full provenance tracking.
  - Eliminates intraprocedural blindspots across `SHIELD-001` (Command Injection), `SHIELD-003` (SSRF), `SHIELD-004` (Arbitrary File Access), and `SHIELD-020` (Read-Exfiltrate Chains).
- **Production API & Contract Stabilization**:
  - Stabilized public library interfaces in `src/lib.rs`.
  - Stabilized IR types (`ScanTarget`, `DataSurface`, `ToolSurface`, `ExecutionSurface`).
  - Production-ready CLI interfaces (`scan`, `guard`, `fix`, `list-rules`, `suppress`, `setup`).
  - Fully integrated VS Code extension v1.0 with inline diagnostics and lightbulb quick-fixes.

## Compatibility

- Guaranteed semantic versioning and backward compatibility across all 1.x releases.
- Offline-first scanning and runtime proxy contracts are preserved across all supported frameworks: MCP, OpenClaw, Hermes Agent, LangChain, CrewAI, GPT Actions, and Cursor Rules.
