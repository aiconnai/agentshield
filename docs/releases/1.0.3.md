# AgentShield 1.0.3 Release Notes

Release date: 2026-11-10

## Scope

AgentShield 1.0.3 ships the GitHub Action exit-code fix that `v1.0.2` lacked, closes several static-analysis evasion paths, and stops egress policy overrides from widening the allowed network surface of `agentshield wrap`.

## Notable changes

- **GitHub Action exit codes**: the composite Action fails when the scanner exits with an unexpected code. With `v1.0.2`, a scanner crash was reported as a passing check.
- **Detection evasion fixes**:
  - Quote-bounded concatenation is no longer treated as a literal argument.
  - Test-file call sites no longer sanitize production functions during cross-file analysis.
  - Interprocedural propagation expands each function once, avoiding exponential traversal on dense call graphs.
- **Egress policy hardening**:
  - Disjoint allow lists merge to deny-all, overlapping lists keep the narrower pattern, and a rate limit of `0` means unlimited.
  - IP addresses are classified by parsed range rather than by text prefix.
  - Domain matching ignores ASCII case and a trailing root dot.

## Behavior changes

- The MCP source walker now scans dot-directories, ignores `.ignore` files, walks up to depth 64 and reads non-UTF-8 files lossily. Expect new findings in files that earlier versions skipped. `.gitignore` is still honored.
- The README no longer documents `pip install agent-shield`; the Python package is not on PyPI.

## Known limitations

- A non-test file that calls a tool handler with a literal argument can still mark that handler's parameter as sanitized and suppress `SHIELD-001`.
- Files listed in `.gitignore` are not scanned.
- The OpenClaw, Vercel AI SDK, Hermes and MCP metadata walkers still skip hidden directories and limit depth.

## Compatibility

- Backward compatible with 1.x configuration, baselines and output formats.
- 722 all-feature tests passing with zero compiler warnings.
- Release invariants verified for `v1.0.3`.
