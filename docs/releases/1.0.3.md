# AgentShield 1.0.3 Release Notes

Release date: 2026-11-10

## Scope

AgentShield 1.0.3 ships the GitHub Action exit-code fix that `v1.0.2` lacked, closes several static-analysis evasion paths, and stops egress policy overrides from widening the allowed network surface of `agentshield wrap`.

## Notable changes

- **GitHub Action exit codes**: the composite Action fails when the scanner exits with an unexpected code. With `v1.0.2`, a scanner crash was reported as a passing check.
- **Detection evasion fixes**:
  - Quote-bounded concatenation is no longer treated as a literal argument.
  - Test-file call sites no longer sanitize production functions during cross-file analysis.
  - Interprocedural propagation no longer explodes on dense call graphs, and paths cut short by the depth limit are recovered through shorter routes.
  - Framework detection and source collection share one walker, so code kept only in a dot-directory or in a file with a non-UTF-8 byte is detected and scanned.
- **Egress policy hardening**:
  - Disjoint allow lists merge to deny-all and overlapping lists keep the narrower pattern.
  - IP addresses are classified by parsed range rather than by text prefix.
  - Domain matching and `per_domain` rate-limit keys ignore ASCII case and a trailing root dot.

## Behavior changes

- **Source collection**: the walker now scans dot-directories, ignores `.ignore` files, walks up to depth 64 and reads non-UTF-8 files lossily. Expect new findings in files that earlier versions skipped, including new entries against existing baselines. `.gitignore` is still honored.
- **Egress blocking**: `block_private` now blocks carrier-grade NAT (`100.64.0.0/10`), and `block_localhost` now blocks `0.0.0.0`, `::` and `*.localhost`. Policies that relied on reaching these destinations need an explicit change.
- **Egress merge**: disjoint allow lists block every destination, and a rate limit of `0` means unlimited when merging, so the other policy's limit applies.
- **Python package**: the README no longer documents `pip install agent-shield`; the package is not on PyPI. Install the SDK from source instead (see the README).

## Known limitations

- A non-test file that calls a tool handler with a literal argument can still mark that handler's parameter as sanitized and suppress `SHIELD-001`.
- Files listed in `.gitignore` (including a parent repository's), files over 1 MiB and directories nested deeper than 64 levels are not scanned. `.git`, `.venv`, `.tox` and `.nox` directories are skipped by name.
- Python string concatenation split across lines inside a call is not classified as interpolated.
- The OpenClaw, Vercel AI SDK and Hermes walkers still skip hidden directories and limit depth.

## Compatibility

- Configuration, baseline and output formats are unchanged from 1.x. The behavior changes above can add findings and block egress destinations that 1.0.2 allowed.
- 732 all-feature tests passing (`cargo test --all-features --locked`, including doctests) with zero compiler warnings.
- Release invariants verified for `v1.0.3`.
