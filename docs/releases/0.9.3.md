# AgentShield 0.9.3 Release Notes

Release date: 2026-08-14

## Scope

AgentShield 0.9.3 introduces the MCP HTTP and Server-Sent Events (SSE) runtime proxy guard, enabling real-time tool inspection and secret redaction for remote MCP servers.

## Notable changes

- **MCP HTTP / SSE Proxy Guard (`src/runtime/mcp_proxy_http.rs`)**:
  - Reverse-proxy between MCP clients (Cursor, Claude, custom agents) and remote HTTP/SSE MCP endpoints.
  - Intercepts incoming `POST` JSON-RPC requests, blocks dangerous or unapproved tool calls, and returns standard JSON-RPC error frames.
  - Intercepts outgoing `GET /sse` Server-Sent Events streams, performing inline regex secret redaction on streamed text and JSON payloads.
  - Added built-in `/health` and `/metrics` JSON telemetry endpoints.
  - Enhanced `agentshield guard` CLI command with `--listen <ADDR>`, `--target <URL>`, and `--audit-log <PATH>`.

## Compatibility

- The HTTP/SSE proxy is available when compiled with `runtime` or `full` features.
- All existing static scanning, autofixing, and stdio proxy contracts remain completely backward-compatible.
