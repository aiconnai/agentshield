# AgentShield 0.9.1 Release Notes

Release date: 2026-08-14

## Scope

AgentShield 0.9.1 introduces the Custom Declarative Rule Engine, enabling organizations and developers to define custom detection policies in YAML or JSON without recompiling Rust code.

## Notable changes

- **Custom Declarative Rule Engine (`.agentshield/rules/*.yaml`)**:
  - Implemented `CustomRuleDef` and `CustomRuleDetector` in `src/rules/custom.rs`.
  - Added source file regex pattern matching with file glob filtering.
  - Added banned dependency checking with organizational rationales.
  - Added prohibited tool name and description matching.
  - Added auto-discovery in `.agentshield/rules/` within the scan root.
  - Added `[rules] custom_dir` in `.agentshield.toml`.
  - Added `--rules-dir <PATH>` CLI option to `agentshield scan` and `agentshield list-rules`.

## Compatibility

- Custom rules integrate seamlessly into existing policy evaluation, suppression handling, SARIF generation, and HTML reporting.
- Built-in rules and CLI contracts remain backward-compatible.
