# AgentShield 0.8.8 Release Notes

Release date: 2026-08-14

## Scope

This release completes backlog items #44 through #50, improving output security, SARIF dataflow fidelity, JSON report metadata, detector coverage, and parser capabilities.

## Notable changes

- Added SARIF 2.1.0 `codeFlows` and `threadFlows` for taint paths, providing step-by-step dataflow tracing in SARIF viewers and GitHub Code Scanning.
- Added run-level policy verdict properties and invocation execution status in SARIF output.
- Added `ScanReport::render(&self, format: OutputFormat) -> Result<String>` library API.
- Added `schema_version` and structured severity summary statistics in JSON reports.
- HTML report XSS escaping for `rule_id`, `target_name`, and `fingerprint`.
- `agentshield suppress` preserves `.agentshield.toml` comments and formatting using `toml_edit`.
- Tightened heuristic precision on SHIELD-007 (Prompt Injection) and SHIELD-014 (Download-Write-Execute).
- Added taint path detection to SHIELD-015 (Overbroad Filesystem Scope).
- Expanded shell parser to support HTTPie (`http`/`https`), `aria2c`, `cargo install`, `gem install`, and `go install`.
- Added bare Python decorator support (`@mcp.tool`, `@tool`) in MCP adapter.
- Added comprehensive unit test suites for High/Critical detectors (SHIELD-013, SHIELD-015, SHIELD-016, SHIELD-017, SHIELD-018).
- Updated VS Code extension activation events and Homebrew tap installation instructions.

## Compatibility

- SARIF 2.1.0 additions (`codeFlows`, run properties) are fully standard-compliant and backward-compatible.
- JSON output additions (`schema_version`, `summary`) are additive and do not alter existing schema fields.
- Console, JSON, SARIF, HTML, and DSSE output contracts remain backward-compatible.

## Readiness

- 542 unit and integration tests passing (`rtk cargo test --all-features`).
- Clippy passes with zero warnings (`rtk cargo clippy --all-features -- -D warnings`).
- VS Code TypeScript compilation verified.
