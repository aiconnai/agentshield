# AgentShield 1.0.1 Release Notes

Release date: 2026-08-19

## Scope

AgentShield 1.0.1 introduces new security detectors (`SHIELD-034`, `SHIELD-035`, `SHIELD-036`), Criterion benchmark and continuous fuzzing infrastructure, strict SARIF 2.1.0 schema compliance, Windows build hardening, and zero-defect security scanner auditing.

## Notable changes

- **New Security Detectors**:
  - `SHIELD-034`: *Insecure Agent Checkpoint / Unsigned State Deserialization* (`torch.load`, `joblib`, `dill`, `cloudpickle`, `shelve`, `PickleCheckpointSaver`).
  - `SHIELD-035`: *Unauthenticated MCP SSE Transport / Missing Origin Validation* (prevention of Cross-Site SSE Hijacking and unauthorized tool execution).
  - `SHIELD-036`: *Tool Response Prompt Injection / Unsanitized Parameter Reflection* (reflection of untrusted arguments via string interpolation and template literals).
- **Hardened Analysis Engine & Infrastructure**:
  - Modularized Composite Flow Engine, Discovery Registry, and MCP Tools extractors.
  - Criterion benchmark suite (`benches/scan.rs`) and `cargo-fuzz` / `libfuzzer-sys` fuzz targets (`fuzz/`).
  - Generative property-based testing with `proptest` (`tests/proptest_parsers.rs`).
- **Standards & Compatibility Hardening**:
  - Conformed SARIF 2.1.0 output schema by correctly placing the `taxonomies` collection on the `run` root.
  - Resolved Windows MSVC conditional compilation imports in discovery subsystem.
  - Fixed synthetic test fixtures in unit tests to eliminate external SAST/Gitleaks false alarms.

## Compatibility

- Full backward compatibility across all 1.x releases.
- 593 default tests and 675 all-feature tests passing with zero compiler warnings.
- Release invariants verified for `v1.0.1`.
