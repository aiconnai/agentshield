# AgentShield 0.9.2 Release Notes

Release date: 2026-08-14

## Scope

AgentShield 0.9.2 enhances the developer IDE experience with the release of the VS Code extension v1.0, featuring Lightbulb Quick-Fix Code Actions and finding suppression actions.

## Notable changes

- **VS Code Extension v1.0 & Quick-Fix Code Actions**:
  - Implemented `AgentShieldCodeActionProvider` providing `CodeActionKind.QuickFix`.
  - Added one-click auto-remediation for fixable findings (`SHIELD-016` Unsafe Deserialization, `SHIELD-009` Unpinned Dependencies).
  - Added inline finding suppression action prompting for rationale and executing `agentshield suppress <fingerprint>`.
  - Added workspace commands: `AgentShield: Auto-Remediate Fixable Findings` (`agentshield.fix`).
  - Added configuration settings: `agentshield.rulesDir` (custom rule directories) and `agentshield.enableQuickFix`.

## Compatibility

- All VS Code configuration settings and command additions are backward-compatible.
- Scanner CLI and library contracts remain unchanged.
