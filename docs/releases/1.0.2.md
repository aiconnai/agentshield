# AgentShield 1.0.2 Release Notes

Release date: 2026-10-14

## Scope

AgentShield 1.0.2 completes composite flow wiring across the public `RuleEngine::run()` entry point and non-MCP framework adapters (`SHIELD-020`), fixes `--ignore-tests` path prefix handling when scan roots lie inside test-named directories (`is_test_file_in`), deduplicates shared adapter, parser, and detector test-helper logic, expands the `SHIELD-001..037` true-positive/false-positive invariant matrix, hardens the VS Code extension dependency tree (`0` vulnerabilities, `-57.5%` dependency count), and optimizes the repository Git packfile (`73.17 MiB -> 1.54 MiB`).

## Notable changes

- **Composite Flow Engine & Adapter Wiring (`SHIELD-020`)**:
  - Wired `compute_composite_flows_for_target` directly into `RuleEngine::run()` (`src/rules/mod.rs`) and `LegacyAnalysisAdapter::load_analysis_with_filter()` (`src/adapter/mod.rs`), ensuring library consumers and non-MCP framework adapters (CrewAI, LangChain, Vercel AI SDK, AutoGen, LlamaIndex, Semantic Kernel) receive full `SHIELD-020` composite toxic flow detection.
- **Test File Exclusion Fix (`--ignore-tests`)**:
  - Added scan-root-aware `is_test_file_in(root, path)` in `src/adapter/mcp/filter.rs` so scanning a project located inside a parent directory named `test/` or `tests/` strips the scan root prefix before evaluating directory segments.
- **Safe-Rust YAML Deserialization (`serde-saphyr`)**:
  - Replaced deprecated `serde_yaml` (and its unmaintained `c2rust` `unsafe-libyaml` dependency, `RUSTSEC-2024-0449`) with 100% safe-Rust `serde-saphyr`, leaving `deny.toml` with zero advisory exceptions (`ignore = []`).
- **Adapter, Parser & Test-Helper Deduplication**:
  - Consolidated shared framework detection, tool declaration mapping, and 3-phase target loading into `src/adapter/pipeline.rs`.
  - Extracted shared sanitizer variable and marker classification helpers into `src/parser/common.rs`.
  - Standardized built-in detector unit test target construction in `src/rules/builtin/test_helpers.rs` (`loc`, `loc_at`, `empty_target`, `make_target_from_files`, `make_target_with_source`, `fixture_findings`).
- **Full `SHIELD-001..037` TP/FP Invariant Matrix**:
  - Completed the true-positive and false-positive invariant matrix in `docs/harness/INVARIANTS.md` across all 37 built-in detectors (`SHIELD-001` through `SHIELD-037`) and wired `tests/fixtures/mcp_servers/vuln_ts_cmd_inject` into automated regression tests.
- **VS Code Extension & Repository Hardening**:
  - Upgraded `@vscode/vsce` to `^4.0.0` in `vscode/package.json`, eliminating all 12 `npm audit` vulnerabilities (`0` vulnerabilities) and shrinking the transitive dependency tree by `57.5%` (`287 -> 122` packages).
  - Pruned historical build artifacts from Git object storage, reducing repository packfile size from `73.17 MiB` to `1.54 MiB`.

## Compatibility

- Full backward compatibility across all 1.x releases.
- 704 all-feature tests passing with zero compiler warnings.
- Release invariants verified for `v1.0.2`.
