# AgentShield 1.1.0 Release Notes

Release date: 2026-11-13

## Scope

AgentShield 1.1.0 hardens trust boundaries across static scanning, baselines, DSSE attestations, runtime MCP proxying, and egress enforcement, while closing the parser, sanitizer, entry-point, and file-walker evasion gaps documented in `1.0.3`.

## Notable changes

- **Framework entry-point tracking (`src/adapter/entry_points/`)**:
  - Tool handlers registered via decorators, factories, class inheritance, or registration calls across Python (`@mcp.tool`, FastMCP, CrewAI, LangChain, AutoGen, LlamaIndex, Semantic Kernel) and TypeScript (Vercel AI SDK `tool({ execute })`, wrappers, aliases) are marked on `ParsedFile::entry_points`.
  - Non-test helper call sites passing literal arguments to a registered tool handler can no longer mark that handler's parameters as sanitized and suppress `SHIELD-001`.
- **Confined, function-scoped path sanitizers**:
  - Sanitized variable tracking is scoped per function instead of per file.
  - `os.path.realpath`, `Path.resolve`, and `path.resolve` count as sanitizers only when paired with a prefix containment check (`os.path.commonpath`, `Path.is_relative_to`, or separator-bounded `startswith`).
- **Hardened shared file walker & scan coverage (`src/adapter/walk.rs`, `src/coverage.rs`)**:
  - MCP, OpenClaw, Hermes Agent, Vercel AI SDK, and adapter auto-detection share one bounded walker that ignores `.gitignore`, `.ignore`, global gitignores, and `.git/info/exclude`.
  - Tooling and dependency directories (`.git`, `.venv`, `venv`, `node_modules`, `.tox`, `.nox`) and linked Git worktrees (verified against enclosing `.git/worktrees/<id>` admin records and backlinks) are pruned only when authentic marker files are present, preventing look-alike directory or forged `.git` file hiding.
  - Walk depth is raised to `512` levels and files are read up to `8 MiB`; pruned, truncated, depth-limited, and unreadable entries are recorded in the additive JSON `coverage` report section.
- **Target configuration trust boundary (`--trust-target-config`)**:
  - Scanning an external path no longer implicitly trusts `.agentshield.toml` suppressions or `.agentshield/rules` inside that target unless `cwd` equals the target, `--config` / `--rules-dir` is passed explicitly, or `--trust-target-config` is set.
- **Scheme-v2 fingerprints & DSSE attestation v2**:
  - Finding fingerprints (`src/rules/fingerprint.rs`) are scan-root-relative, resilient to line edits above a finding, and disambiguated per occurrence; `agentshield scan --write-baseline` writes `schema_version = 2` while continuing to read `v1` baselines.
  - `agentshield certify` emits `https://agentshield.dev/attestation/v2` statements binding `subject.digest.sha256` to a deterministic SHA-256 manifest of scanned file contents and signing the standard `DSSEv1` pre-authentication encoding (PAE).
- **Parser accuracy across Python, TypeScript, and Shell**:
  - Multi-line Python calls and string concatenations are joined prior to taint classification, and `import` / `from ... import ... as` aliases resolve to their canonical targets.
  - TypeScript `exec` / `execSync` sinks resolve against `child_process` / `node:child_process` imports instead of matching `RegExp.exec`.
  - Shell parser distinguishes non-executing data arguments from `sh`/`bash`/`zsh`/`dash`/`ksh` `-c` command strings, including combined flags (`-ec`, `-lc`).
- **Runtime guard, MCP proxy & egress hardening**:
  - `agentshield guard` fails closed when `--config` or `.agentshield.toml` fails to load.
  - Stdio and HTTP/SSE MCP proxies inspect every element of JSON-RPC batches and enforce strict RFC 9112 HTTP/1.1 header framing (`Content-Length` / `Transfer-Encoding`), HTTP method (`POST`/`GET`/`HEAD`/`DELETE`/`OPTIONS`), and JSON body validation.
  - `agentshield wrap` normalizes hosts and domain rules with IDNA (UTS #46), rejects empty-label domain patterns at load time, unwraps IPv6-embedded IPv4 ranges and `0.0.0.0/8`, connects directly to verified resolved IPs, sets `ALL_PROXY`/`all_proxy`, and strips `NO_PROXY`/`no_proxy`.
  - Console and HTML renderers escape terminal control sequences and CWE/finding metadata.

## Behavior changes

- **Ignore files are not honored**: `.gitignore` (and parent `.gitignore` files) no longer hide files from scans. Add intentional workspace exclusions (such as local developer worktrees) to `[scan] exclude` in `.agentshield.toml` or pass `--exclude`.
- **Untrusted target configs**: Running `agentshield scan /path/to/repo` from a different working directory ignores `/path/to/repo/.agentshield.toml` and `/path/to/repo/.agentshield/rules` by default and logs a notice to `stderr`. Pass `--trust-target-config` when scanning trusted repositories from outside their root.
- **Baseline & attestation upgrades**: Newly written baselines use `schema_version = 2` and newly generated attestations use `https://agentshield.dev/attestation/v2` with standard DSSE PAE signatures. Legacy `v1` baselines and `v1` envelopes remain readable/verifiable via legacy compatibility paths.
- **Egress environment & invalid patterns**: `wrap` removes `NO_PROXY`/`no_proxy` from wrapped child processes and rejects malformed domain patterns such as `*.` when loading an egress policy.

## Compatibility

- CLI flags, configuration files, SARIF 2.1.0, HTML, and JSON output contracts remain backwards-compatible with 1.x (JSON scan output adds the optional `coverage` object).
- 1032 all-feature tests passing (`cargo test --all-features --locked`, including unit, integration, interop, property, and doc tests) with zero compiler or Clippy warnings and zero `cargo deny` advisories.
- Release invariants verified for `v1.1.0`.
